# 安全指南（强制性检查）

## 提交前必查

- [ ] 无硬编码密码
- [ ] 所有用户输入已验证
- [ ] SQL 注入防护（参数化查询）
- [ ] XSS 防护（HTML 已净化）
- [ ] CSRF 保护已启用
- [ ] 认证/授权已验证
- [ ] 所有端点有速率限制
- [ ] 错误消息不泄露敏感数据

## 机密管理

- [必须]  使用环境变量或机密管理器
- [必须]  启动时验证机密是否存在
- [禁止] 源代码中硬编码机密
- [禁止] 日志中记录敏感信息

## 安全响应协议

发现安全问题：
1. 立即停止
2. 使用 **security-reviewer** agent
3. 先修复 CRITICAL 问题
4. 轮换已暴露的机密
5. 审查整个代码库

## 禁止行为

- [禁止]  使用弱加密算法（MD5、SHA1）
- [禁止]  明文存储密码
- [禁止]  信任用户输入
- [禁止]  错误消息暴露敏感信息

# 编码风格（强制性约束）

## 不可变性

- [必须]  创建新对象，不修改现有对象
- [必须]  使用不可变数据结构和写时复制
- [禁止] 原地修改

## 文件组织

- [必须]  多个小文件优于大文件
- [必须]  文件大小：200-400 行（最多 800 行）
- [必须]  按功能/领域组织，不按类型
- [必须]  高内聚，低耦合

## 错误处理

- [必须]  每层明确处理错误
- [必须]  UI 提供友好错误消息
- [必须]  服务器记录详细错误上下文
- [禁止] 静默吞掉错误

## 输入验证

- [必须]  系统边界验证所有用户输入
- [必须]  使用 schema 验证（可用时）
- [必须]  快速失败，清晰错误消息
- [禁止] 信任外部数据

## 函数大小

- [必须]  函数 <50 行
- [禁止] 深层嵌套（<4 层）

## 禁止行为

- [禁止]  硬编码值（用常量或配置）
- [禁止]  原地修改（用不可变模式）
- [禁止]  静默吞掉错误

## 代码质量检查清单（提交前）

- [ ] 代码可读且命名良好
- [ ] 函数很小（<50 行）
- [ ] 文件专注（<800 行）
- [ ] 无深层嵌套（<4 层）
- [ ] 正确的错误处理
- [ ] 无硬编码值
- [ ] 无原地修改
